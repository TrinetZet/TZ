# Мини-калькулятор для Android

Небольшое нативное приложение на Kotlin и Jetpack Compose. Поддерживает цифры, сложение, вычитание, умножение, деление, вычисление результата и полный сброс.

## Как скачать APK на телефон

1. Откройте вкладку **Actions** репозитория.
2. Выберите последний успешный запуск **Build Android Calculator**.
3. Внизу страницы скачайте архив **minimal-calculator-apk** из раздела **Artifacts**.
4. Распакуйте ZIP-файл на телефоне.
5. Откройте `app-debug.apk`.
6. Если Android попросит разрешение, временно разрешите установку приложений из браузера или файлового менеджера.

Это тестовая debug-сборка, не предназначенная для публикации в Google Play.

## Возможности

- операции `+`, `−`, `×`, `÷`;
- целочисленный и десятичный результат вычисления;
- сообщение `Нельзя делить на ноль` вместо аварийного завершения;
- тёмный интерфейс;
- сохранение набранного выражения при пересоздании экрана.

## Локальная проверка

Требуются JDK 17 и Android SDK 36.

```bash
cd android-calculator
./gradlew clean :app:testDebugUnitTest :app:assembleDebug
```

После успешной сборки APK находится здесь:

```text
app/build/outputs/apk/debug/app-debug.apk
```
