# TaskCapture Android
Выделенный текст → «Создать задачу» → локальная модель → бэклог. Без подтверждения.
Если приложение не показывает пункт обработки выделения, используйте «Поделиться» → TaskCapture.

## Установка
В успешном GitHub Actions run откройте артефакт TaskCapture-Android-APK, скачайте ZIP и распакуйте APK.
Откройте APK на Android и разрешите установку из выбранного файлового менеджера.
Тестовая версия 0.1.0, Android 8.0+, arm64-v8a. Встроенные веса Qwen3 0.6B Q4_K_M занимают 396 705 472 байта.
Нужен запас свободного места: APK и приватная копия весов. Первый запуск обработки копирует модель.
Сборка подписана тестовым debug-ключом; смена ключа в следующих сборках может потребовать удаления приложения с потерей базы.
Удаление приложения удаляет задачи. Экспорт, ручное создание, OCR и Windows не входят в первую версию.

## Поведение
Исходник записывается сразу, затем WorkManager обрабатывает очередь последовательно.
Android может откладывать фоновую обработку; открытие бэклога повторно ставит незавершённые задачи в очередь.
В список попадает одна задача на одно выделение. Модель формирует заголовок и описание.
Обрабатываются первые 600 Unicode-символов; полный исходник до 65 536 символов остаётся в карточке.
Обработка ограничена пятью минутами; скорость зависит от устройства и будет проверена на реальном Fold пользователем.
При ошибке исходник сохраняется, доступен повтор. Модель может ошибаться в смысле текста — исходник доступен для сравнения.
Данные хранятся в SQLite, бэкап отключён, INTERNET отсутствует.
Горячая клавиша Windows — будущий отдельный этап.

## Сборка
Java 17, Android SDK 36, build-tools 36.0.0, NDK 28.2.13676358, CMake 3.22.1, Gradle 8.13, AGP 8.13.2.
Из каталога taskcapture-android:

    python3 scripts/prepare-dependencies.py
    ./gradlew testDebugUnitTest assembleDebug

Сеть нужна только сборочному хосту. Источники и хэши в dependencies.lock.json.
Для эмулятора: -PtestAbi=x86_64. Устанавливаемый артефакт собирается отдельно для arm64.

## Проверки
Unit: входной текст, JSON-результат, размер/Unicode/специальные маркеры промпта.
Android: SQLite, повторная доставка, восстановление claim, ошибка/повтор; PROCESS_TEXT и SEND, реальная модель, UI, отсутствие INTERNET.
Host: тот же C++ engine на 10 синтетических русских текстах; отчёт проверяет структуру, не гарантирует семантическую точность.
См. docs/PROGRESS.md для фактически выполненных проверок.


## TaskCapture Glass 0.2.0

Скопируйте текст, затем нажмите **TC** в шторке. В приложении кнопка «TC в шторке» запускает системное добавление плитки на Android 13+; на остальных версиях добавьте её через редактирование быстрых кнопок. Короткое стеклянное подтверждение означает, что текст уже сохранён. Обработка моделью продолжается отдельно.

Статусы задач: **Бэклог / В работе / Выполнено**. Галочка в списке завершает задачу и возвращает её в бэклог при повторном нажатии. В карточке можно выбрать любой статус.

**Экспорт → Поделиться .md / Сохранить .md** выгружает все задачи, включая выполненные и необработанные, независимо от фильтра. Полный исходный текст включён.

### Установка и данные прежней версии

Первая APK 0.1.0 подписана временным ключом runner; прежний приватный ключ не сохранён. Glass использует отдельный package com.trinetzet.taskcapture.glass и устанавливается рядом с прежней версией. **Не удаляйте старое приложение, если в нём есть нужные задачи.** Его данные сохраняются отдельно; автоматического переноса между приложениями нет. Миграция SQLite v1→v2 проверяется для совместимого обновления базы.

Подпись этой тестовой сборки также временная. Для следующих обновлений нужна настройка постоянного signing key в защищённых GitHub Actions secrets; приватный ключ никогда не должен попадать в репозиторий или release. Бесшовное обновление поверх этой APK пока не гарантируется.

Проверки: unit-контракты, миграция/статусы/очередь, реальный clipboard/tile capture, restricted FileProvider, офлайн inference, screenshots с включёнными анимациями, увеличенным шрифтом и широким экраном. Эмулятор не заменяет проверку физического Samsung Fold.

Известное небольшое ограничение: если повернуть экран в короткий момент подготовки экспорта, до открытия системного меню, нужно нажать экспорт повторно. Уже выбранный снимок для открытого меню сохранения восстанавливается.
