# Локальные данные
Приложение принимает только явно переданный выделенный текст. Оно не читает переписки в фоне.
Текст, исходник и результаты хранятся в приватной SQLite-базе приложения.
Модель и инференс локальные; разрешения INTERNET нет. Телеметрии и удалённых API нет.
Системный автоматический бэкап базы отключён. Удаление приложения удаляет базу.
В системные логи не выводятся пользовательские тексты, промпты и ответы модели.
Для автотестов используются только синтетические примеры.
