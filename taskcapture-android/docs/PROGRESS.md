## Ограничения
Одна выделенная запись создаёт одну задачу. Модель получает первые 600 Unicode-символов; полный исходник до 65 536 символов сохраняется.
Android может отложить фоновую обработку; открытие бэклога повторно ставит незавершённые задачи в очередь.
Инференс ограничен пятью минутами, выход — 256 токенами; скорость на Fold ещё не измерена.
PROCESS_TEXT доступен только в поддерживающих его сторонних приложениях. Альтернатива — системное «Поделиться».
APK тестовый: новый debug-ключ в следующей сборке может потребовать удаления приложения, что удаляет задачи. Стабильный production signing не обещается.
Нужно место для APK и приватной копии модели (396 705 472 байта).

## Решения при реализации
- Java вместо Kotlin, по образцу существующего Android-проекта; цена возможной будущей миграции.
- Отдельная ветка feat/taskcapture-android и изолированный checkout; master не объединяется.
- Helper-ресурсы Superpowers недоступны: ledger и проверки поддерживались вручную.
- 600 символов вместо сложной обрезки токенов: патологический ввод может потребовать более короткого выделения.
- WorkManager APPEND_OR_REPLACE с сериализацией: возможна задержка ОС; запись текста не зависит от инференса.
- Debug signing для личной установки: возможна смена ключа между сборками.
- Завершение/ошибка по токену владения попыткой: старый worker не затирает новую попытку.
- Release-оптимизация нативных ядер внутри debug APK: менее удобная нативная отладка.
- x86_64 тестовая сборка использует SSE4.2/AVX/F16C эмулятора; доставляемая arm64 сборка от этих флагов не зависит.
- Число потоков min(4, аппаратное число); максимум пять минут инференса без обещания SLA.
- Insets применены для API 36; вывод подписанта отделён от JSON проверки.
- Исправлен тест, завершавший pending-попытку без claim: complete требует активного владельца.
- После connectedDebugAndroidTest Gradle удаляет тестовое приложение; лишний запуск диагностического экрана убран, чтобы не выдавать новую установку за сохранённые данные.
- Публикация versioned prerelease только после успешных APK и Android jobs.

## Неполные проверки
Отдельные полноценные сценарии физического убийства процесса, заполненного диска и пересоздания Activity не покрыты полностью. Проверки SQLite/токена попытки/прерванного файла пройдены. Физический телефон пользователя пока не проверен.
