# TaskCapture Glass для Windows

Выделите текст в любом приложении → нажмите выбранную горячую клавишу → TaskCapture автоматически сохранит задачу в Бэклог и сформирует заголовок/описание локальной моделью. Internet для работы не нужен.

## Первый запуск
Установите Setup для Windows x64 (основная платформа Windows11). Выберите сочетание (по умолчанию Ctrl+Shift+T), создайте или откройте MD-файл TaskCapture для Windows и задайте этапы. Все три текста задачи — заголовок, описание, исходник — и статусная модель находятся в этом файле. Модель уже существующего файла изменяется через «Этапы задач», с сохранением идентификаторов; в настройках открытого файла она показана только для чтения. В трее приложение продолжает слушать сочетание; двойной щелчок открывает окно, «Выход» завершает работу. Автозапуск при входе опционален.

В списке выбирайте этап, в редакторе изменяйте три текста и нажимайте «Сохранить» или Ctrl+Enter: MD обновляется сразу. «Этапы задач» позволяет добавлять и переименовывать стадии, отмечать завершённые. Бэклог обязателен. Этап с задачами удалить нельзя, сначала переведите задачи в другой. Изменение пути переключает реестр; прежние задачи остаются в прежнем MD.

## Хранение и надёжность
Только MD хранит задачи; настройки пути/клавиши находятся в LocalAppData. Три текстовых поля читаемы в fenced Markdown. Служебные HTML-комментарии держат ID/этапы/состояние обработки и должны сохраняться при внешнем редактировании. MD не-TaskCapture не перезаписывается. Корректные внешние изменения перечитываются; повреждённый или удалённый файл вызывает сообщение. Предыдущая версия сохраняется в `.bak` (если он защищён, в отдельном `.replaced-*.md`). Одновременные внешние записи обнаруживаются по версии, действительно заменённой атомарной операцией; конфликтующие версии сохраняются рядом в `.conflict-*.md` и приложение сообщает об этом. `.taskcapture.lock` блокирует второй экземпляр на том же реестре. Сетевые диски/облачные конфликтующие записи не обещают распределённую блокировку.

Ручные изменения текстов защищены от позднего результата модели, статусы не сбрасываются при обработке. Ошибка модели оставляет исходник и кнопку повторения. Захват до65536 UTF16 символов; модель обрабатывает первые600 Unicode code points, полный исходник хранится.

## Ограничения
Копирование выполняется как Ctrl+C и заменяет буфер выделенным текстом. Приложение, которое не поддерживает обычное копирование выделения, защищённое поле или окно с более высокими правами может не отдать текст. Старый буфер не превращается в задачу при отсутствии нового копирования. OCR не добавлен в этот выпуск. Не запускайте TaskCapture с повышением прав ради обхода защищённых полей.

Windows x64 с SSE4.2 и AVX; native runtime собран без AVX2/FMA/F16C, без GPU и curl. .NET10 self-contained входит в дистрибутив. Установщик текущего пользователя без администратора. Дистрибутив не подписан платным сертификатом, SmartScreen может показать предупреждение. macOS/Linux, ARM64 и синхронизация с Android не входят в текущий выпуск. Стекло рисуется средствами WPF, Windows11 backdrop при наличии; анимации учитывают системное отключение.

## Сборка и проверки
`dotnet run --project Core.Tests -c Release` — реальные операции MD, внешние изменения/конфликты, Unicode, статусы и prompt/output contracts.
`dotnet run --project Windows.Tests -c Release` — Win32 клавиша/копирование из отдельного процесса/старый буфер/скрытое окно, редактор и WPF layouts.
GitHub Actions компилирует закреплённую llama.cpp, проверяет SHA модели Qwen3 0.6B, реальную генерацию на десяти русских текстах, self-contained пакет и установку/удаление. Скриншоты — реальный WPF render, не макеты. Физический пользовательский ПК отдельно не тестировался.

Лицензии llama.cpp и Qwen входят в runtime; закреплённые версии — `../taskcapture-android/dependencies.lock.json`.
