# Минимальный Android-калькулятор — дизайн

Дата: 19 сентября 2026 г.

## Цель

Создать в репозитории `TrinetZet/TZ` небольшой нативный Android-проект, который подтверждает полный мобильный цикл: исходники хранятся в GitHub, GitHub Actions собирает устанавливаемый debug APK, а пользователь скачивает его на Android-телефон.

## Границы

Проект размещается в отдельной папке `android-calculator/`. Существующие HTML-файлы в корне репозитория не изменяются.

Первая версия поддерживает:

- цифры от 0 до 9;
- сложение, вычитание, умножение и деление;
- вычисление результата кнопкой `=`;
- полный сброс кнопкой `C`;
- понятное сообщение при делении на ноль;
- простой тёмный интерфейс.

История вычислений, скобки, проценты, память, научные функции и публикация в Google Play не входят в первую версию.

## Технологический подход

- Kotlin;
- Jetpack Compose для интерфейса;
- Gradle;
- Material 3;
- минимальная версия Android, совместимая с современными телефонами;
- GitHub Actions для сборки debug APK.

## Архитектура

Приложение состоит из трёх небольших частей:

1. Чистая логика вычислений, принимающая два числа и выбранную операцию.
2. Состояние калькулятора: текущее число, сохранённый операнд, выбранная операция и текст ошибки.
3. Один Compose-экран с дисплеем и сеткой кнопок.

Логика вычислений не зависит от Android API, поэтому её можно проверять обычными модульными тестами.

## Поведение

Пользователь вводит первое число, выбирает операцию, вводит второе число и нажимает `=`. Дисплей показывает результат. `C` возвращает калькулятор в начальное состояние. При делении на ноль приложение не завершается аварийно, а показывает сообщение «Нельзя делить на ноль».

Повторный выбор операции до ввода второго числа заменяет ранее выбранную операцию. Ввод новой цифры после результата начинает новое вычисление.

## Проверка

Модульные тесты покрывают четыре арифметические операции и деление на ноль. Локальная или облачная проверка должна выполнить тесты и собрать debug APK.

Workflow запускается при изменениях внутри `android-calculator/` и вручную. Результат публикуется как artifact с понятным именем, чтобы APK можно было скачать на телефон из GitHub Actions.

## Критерии готовности

- проект находится в `android-calculator/`;
- Gradle-проект успешно собирается;
- модульные тесты проходят;
- GitHub Actions формирует APK;
- APK устанавливается и запускается на Android;
- четыре операции, `=` и `C` работают;
- деление на ноль не приводит к падению приложения.
