# TaskCapture Windows — design

Пользователь устанавливает TaskCapture, выбирает глобальное сочетание, MD-файл и статусы. Выделение в другом приложении + сочетание без подтверждения сохраняет задачу в Бэклог, локальная модель формирует заголовок и описание. Сам пользователь редактирует три текста и статус; изменения немедленно сохраняются в выбранный Markdown. Монохромное стекло, плавные переходы и ненавязчивая анимация успеха соответствуют Android Glass.

## Delivery and choices
Windows x64, основная цель Windows 11; .NET 10 WPF self-contained и установщик Inno Setup для текущего пользователя, без администратора. Дополнительно portable ZIP. Отдельная ветка feat/taskcapture-windows той же репы. macOS/Linux и синхронизация с Android не входят в этот выпуск. WPF выбрана вместо Electron (более тяжёлый браузерный runtime) и Tauri (больше новой инфраструктуры Rust/WebView). Windows runner проверяет реальные сценарии и установку; физический ПК пользователя не объявляется проверенным.

## Storage
Один UTF-8 MD — единственный источник задач и статусной модели, без скрытой task-DB. Служебные HTML-комментарии содержат только метаданные формата, ID, состояния обработки и модели статусов; заголовок, описание, исходник — читаемые отдельные блоки fenced Markdown. Длина fence подбирается по содержимому, Unicode и любые Markdown-разделители сохраняются точно. Файл не-TaskCapture, неправильный формат и неизвестный статус вызывают ошибку; существующие произвольные файлы не перезаписываются. Запись через временный файл, flush и атомарную замену; предыдущая версия — .bak. Сериализация операций, проверка внешнего изменения перед заменой, отдельный lock-файл против двух экземпляров на одном MD. При ошибке записи успех не показывается. Внешние корректные изменения перечитываются, некорректные не затрагиваются. Удалённый открытый файл не создаётся заново молча.

## Tasks and stages
TaskItem: Id, Title, Description, Source, StageId, CreatedUtc, ContentRevision, Processing (pending/ready/error), Error. Максимум захвата 65 536 UTF-16 символов, полный исходник хранится; модель использует первые600 Unicode code points. Заголовок при захвате — первая строка, описание пустое до LLM. Обязательный этап backlog/Бэклог; остальные этапы пользователь добавляет, переименовывает, отмечает завершёнными и удаляет, только если они не используются. По умолчанию Бэклог/В работе/Выполнено. Задачи не теряются при настройке статусов или смене пути. Редактор сохраняет тексты одной операцией по кнопке «Сохранить»/Ctrl+Enter, статус меняется сразу. Изменения стадии не сбрасываются inference; ручные изменения текста защищены ContentRevision, модель их не перезаписывает. Ошибка модели оставляет сохранённый исходник и кнопку повторить. Очередь последовательна и возобновляется после запуска.

## Capture and runtime
RegisterHotKey + MOD_NOREPEAT, конфликт сочетания явно сообщается, старое сочетание сохраняется при неудаче. На событие дождаться отпускания физических модификаторов, сохранить foreground HWND и sequence буфера, SendInput Ctrl+C, дождаться нового Unicode text только если sequence изменился и foreground не поменялся. Без выделения — сообщение, задача не создаётся. Приложения с правами администратора/защищённым полем могут блокировать копирование; без OCR fallback. Копирование заменяет буфер выделенным текстом как обычный Ctrl+C; не обещаем восстановление всех частных clipboard-форматов. Capture не перехватывает фокус, toast ShowActivated=false. Глобальные клавиши работают, пока приложение в трее, закрытие окна скрывает его; пункт «Выход» завершает процесс. Автозапуск опционален.
Локальная Qwen3 0.6B и CPU llama.cpp той же закреплённой версии, без сетевого обращения на пользовательском ПК. Native worker — отдельный процесс, UTF-8 stdin/stdout, Unicode model path, JSON grammar, дедлайн300сек и максимум4CPU threads. Весь runtime, лицензии и модель в дистрибутиве. Настройки — LocalAppData, задачи только MD. Runtime hash проверяется до inference; ошибка не уничтожает данные.

## UI and evidence
Main: серебристый glass-sidebar с фильтрами/счётчиками, список задач с этапами, заголовком и описанием, редактор трёх текстов, настройки пути/сочетания/статусов. Первый запуск требует настройки. Системные настройки reduced motion соблюдаются. Минимальные размеры, scroll и resizable окно, крупный шрифт не скрывает сохранение. Успех только после durable write; статус процесса отображается отдельно. Цвета графит/белый/серебристый, без зелёного. Кодовые WPF-градиенты и световые слои, Windows 11 DWM backdrop при наличии, fallback для других Windows. Никаких обещаний точного iOS optical rendering.
Проверки: MD round-trip/Unicode/fences, malformed/external conflict/backup/потерянный файл, status constraints, inference/manual-edit race, restart, keyboard conflicts and actual selected-text hotkey in separate process, no-selection stale clipboard, реальная модель, WPF screenshots/narrow window/reduced motion, silent installer/uninstaller с сохранением MD. Отдельный независимый reviewer перед выпуском. Дистрибутив не подписан платным code signing; Windows SmartScreen может предупредить, не предлагаем отключать защиту.

## Authorization
Пользователь явно разрешил продолжать без согласований. Выбор реализации и публикация в новой feature-ветке выполняются автономно; master и Android не меняются.
